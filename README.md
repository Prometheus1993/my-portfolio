# Jesus O'Bulan's Portfolio

I'm a fullstack developer based in Antwerp. This is where I share my projects, the decisions behind them, and what I've learned along the way.

[jesusobulan.xyz](https://jesusobulan.xyz)

## Design

Inspired by the YoRHa menus in NieR:Automata: muted colors, condensed headings, HUD details, and subtle grain. A boot sequence and keyboard command palette carry that influence through the site.

## Highlights

- **Case studies** covering the work, technical choices, and outcomes of selected projects.
- **AI assistant** that answers questions about my experience, skills, and projects using Google Gemini and the Vercel AI SDK.
- **Command palette** for quick navigation with `⌘K` or `Ctrl+K`.
- **Blog** with notes from my software development internship at Brightest.

## Tech stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Framer Motion · GSAP · Lenis · Vercel AI SDK
